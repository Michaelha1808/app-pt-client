## Nguyên tắc

1. **Không code mới trước bảo vệ**. Chỉ chuẩn bị sửa tính năng đã có.
2. **Không refactor "cho gọn"**. Bảo vệ không phải lúc dọn code.
3. **Luôn tag + backup trước khi sửa**. Xem `03-SAFETY-CHECKLIST.md`.
4. **Rehearse 4 tình huống mẫu** trước bảo vệ 1–2 hôm — xem cuối `03-SAFETY-CHECKLIST.md`.
